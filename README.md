# Meu Portal de Entretenimento Digital 🎬🎵🎮

## 📌 Sobre o projeto

O **Meu Portal de Entretenimento Digital** é uma página web desenvolvida como atividade prática de HTML e CSS.

O objetivo é apresentar conteúdos de entretenimento de forma organizada e visual, divididos em três categorias: filmes e séries, música e podcasts, games e tecnologia.

## 🖥️ Seções do portal

- **Filmes e Séries:** novidades, lançamentos e recomendações.
- **Música e Podcasts:** músicas, artistas e podcasts.
- **Games e Tecnologia:** jogos, novidades tecnológicas e lançamentos.

## 🛠️ Tecnologias utilizadas

- HTML5 – Estruturação da página.
- CSS3 – Estilização e organização dos elementos.
- Flexbox – Organização das seções em colunas.
- CSS Reset – Padronização dos estilos da página.

## 🎨 Recursos utilizados

- Três seções organizadas em colunas.
- Imagens padronizadas.
- Estilização de títulos e textos.
- CSS interno, externo e inline.
- Utilização de classes e IDs.
- Comentários para organização do código.

## ▶️ Como visualizar o projeto

1. Baixe ou clone os arquivos do projeto.
2. Abra a pasta no Visual Studio Code.
3. Localize o arquivo `portal.html`.
4. Abra o arquivo em um navegador para visualizar a página.

## 📚 Objetivo acadêmico

Esta atividade foi desenvolvida com o propósito de praticar os conceitos de HTML e CSS, explorando diferentes formas de estilização e organização de uma página web.
